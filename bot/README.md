# 자동매매 프로그램

매주 실제 시세로 정해진 규칙대로 사고팔고, 나중에 한국투자증권 계좌에 그대로 연결하는 프로그램입니다.
필요한 것: 노드(Node.js) 18 이상. 다른 설치는 없습니다.

## 파일
| 파일 | 하는 일 |
|---|---|
| `engine.js` | 규칙 계산 엔진. 전략 시험실과 똑같은 코드 |
| `config.json` | 규칙 값(고르는 기간, 평균선, 손절 등)과 가상계좌 시작일 |
| `update_data.js` | 주간 시세 자료 갱신 (아직 안 끝난 주는 자동 제외, 이상한 값은 멈춤) |
| `paper.js` | 가상계좌 계산 → `../paper/state.json` |
| `validate.js` | 실수 방지 점검 11가지 (미래 자료 안 쓰는지, 돈 계산 검산 등) |
| `kis.js` | 한투 오픈API 연결 (토큰·시세·잔고·매수가능금액·주문) |
| `kis_trade.js` | 가상계좌의 '목표 보유'에 맞춰 한투 계좌에 주문 |
| `mock_kis.js`, `test_kis.js` | 가짜 한투 서버로 연결부 시험 |

## 매주 순서 (자동 예약 작업이 함)
1. 토요일 아침: 시세 갱신 → `node update_data.js ...` → `node paper.js` → `node validate.js`
2. (한투 연결 후) 월요일 밤 미국 장 전: `node kis_trade.js` 로 확인 → `node kis_trade.js --live` 로 주문

## 한투 연결 방법 (계좌 생긴 뒤)
컴퓨터의 `~/.kis/kis.json` 에 아래처럼 저장합니다. **이 파일은 저장소에 올리지 마세요.**
```
{ "mode": "demo", "appkey": "모의투자 앱키", "appsecret": "모의투자 앱시크릿", "cano": "모의계좌 앞 8자리", "prdt": "01" }
```
`mode`를 `demo`(모의) → 충분히 확인 뒤 `real`(실전)로 바꿉니다.

## 확인된 것 / 실제 계좌로 확인해야 할 것
- 확인: 주소·거래코드·항목 이름은 한투 공식 저장소(koreainvestment/open-trading-api) 2026-10 기준.
- 계좌로 확인 필요: 모의 매도 코드(설명 VTTT1001U, 예제 코드 VTTT1006U로 서로 다름 → 하나 실패 시 다른 것 자동 재시도),
  에스앤피500·금 상품의 주문 거래소 코드(AMEX로 설정), 실전에서 매도 대금으로 같은 날 바로 매수가 되는지, 최소 수수료 여부.
