# 맥미니 자동매매 서버 설치 안내

맥미니를 집에 24시간 켜 두고, 자동매매 프로그램을 매주 저절로 돌리는 방법입니다.
**사장님이 하실 일은 1~4단계(약 40분)**, 프로그램 설치는 맥미니에 연결된 클로드가 합니다.

## 준비물
- 맥미니, 전원선
- 처음 한 번만: 모니터(에이치디엠아이 선), 키보드, 마우스
- 인터넷 (공유기 선 연결 권장)

## 1단계. 맥 처음 켜기 (사장님)
1. 모니터·키보드·마우스·인터넷을 연결하고 전원을 켭니다.
2. 화면 안내대로 언어(한국어), 지역(대한민국), 와이파이, 애플 계정을 설정합니다.
3. **"파일볼트(디스크 암호화)"를 켤지 물으면 → 끄기** 를 고릅니다.
   - 켜 두면 정전 뒤 다시 켜질 때 비밀번호를 직접 쳐야 해서 그동안 프로그램이 멈춥니다.
4. 맥 사용자 비밀번호는 꼭 따로 적어 두세요.

## 2단계. 꺼지지 않게 설정 (사장님)
**시스템 설정**(화면 왼쪽 위 사과 모양 → 시스템 설정)에서:
1. **에너지** → "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지" 켜기, "정전 후 자동으로 시작" 켜기
2. **사용자 및 그룹** → "자동으로 로그인" → 내 계정 선택 (정전 뒤에도 프로그램이 돌게)
3. **일반 → 소프트웨어 업데이트** → (i) 버튼 → "업데이트 설치"는 끄고 "업데이트 확인"만 켜기
4. **일반 → 날짜 및 시간** → 시간대가 **서울**인지 확인
메뉴 이름은 맥 버전마다 조금 다를 수 있습니다. 못 찾으면 화면을 찍어 클로드에게 보내세요.

## 3단계. 노트북에서 들어갈 수 있게 (사장님)
1. 맥미니에서 사파리로 **remotedesktop.google.com/access** 접속 → 구글 계정 로그인
2. "원격 액세스 설정" → 내려받기 → 설치 → 이름과 6자리 숫자 비밀번호 정하기
3. 맥이 권한을 물으면(화면 기록, 손쉬운 사용) 전부 허용
4. **노트북** 크롬에서 같은 주소에 들어가 맥미니가 보이는지, 조작되는지 확인

## 4단계. 클로드 연결 (사장님)
1. 맥미니에 **클로드 데스크톱 앱**을 설치하고 로그인
2. 이 대화를 맥미니의 클로드 앱에서 열고 "맥미니 연결했어"라고 보내기

## 5단계. 프로그램 설치 (클로드가 함)
클로드가 맥미니에서 아래를 직접 진행합니다. 사장님은 비밀번호를 물을 때만 입력하시면 됩니다.
1. 노드(프로그램 실행기) 설치
2. 저장소 받기, 사이트 올리기용 깃허브 로그인
3. 알파 밴티지 무료 키 등록 (사장님이 이메일로 받은 키를 붙여 넣기)
4. `bot/mac/install.sh` 실행 → 매주 자동 실행 2개 등록 → 시험 실행
   - **토요일 08:43** 주간 실행: 시세 받기 → 가상계좌 진행 → 점검 11가지 → 통과하면 사이트에 올림
   - **화요일 00:05** 주문 실행 (미국 월요일 장 중): 한투 설정이 없으면 아무것도 안 함
5. 정상 확인 뒤, 지금 클로드 쪽에서 돌리던 주간 예약 작업은 끔 (두 곳에서 같이 올리지 않게)

## 6단계. 모니터 빼기 (사장님)
노트북에서 원격 접속이 되는 걸 확인했으면 모니터·키보드·마우스를 빼도 됩니다.
원격 화면이 작거나 흐리면 "에이치디엠아이 더미 플러그"를 꽂아 두면 해결됩니다.

## 한투 계좌가 생긴 뒤 (클로드와 함께)
1. 모의투자 앱키를 `~/.kis/kis.json` 에 저장 (`"mode": "demo"`, 처음엔 `"auto"` 없이)
2. 화요일 확인만 실행 결과를 몇 주 보고, 공식 자료끼리 다른 부분 3가지(모의 매도 코드, 거래소 코드, 같은 날 재매수)를 확인
3. 문제없으면 `"auto": true` 로 모의투자 자동 주문
4. 실제 돈은 그 뒤에 따로 결정 — `"mode": "real"` 과 실전 앱키로 바꿈

## 안전장치 정리
- 점검이 하나라도 실패하면 사이트에 안 올리고, 그 주 주문도 하지 않음
- 자료가 10일 넘게 오래됐으면 주문하지 않음
- 한투 비밀값은 맥미니 `~/.kis` 폴더에만 있고 저장소에는 절대 올라가지 않음
- 자동 실행을 끄려면: `bot/mac/uninstall.sh`

## 문제가 생기면
- 실행 기록: `bot/logs/` 폴더 (`status.txt`에 매주 성공/실패 한 줄)
- 맥 오른쪽 위 알림으로 성공/실패가 뜸
- 클로드에게 "맥미니 자동매매 점검해줘"라고 하면 기록을 보고 고침
